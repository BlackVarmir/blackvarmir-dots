# Чеклист продуктивності BlackVarmir

Мета: система відгукується миттєво, анімації йдуть рівно, ноутбук не гріється без потреби.
Більшість пунктів `install.sh` робить сам. Тут описано, що саме налаштовано, навіщо і як це перевірити.

Позначки: ✅ робить `install.sh` · ⚙️ уже в конфігах · 🖐 потрібно зробити вручну

---

## 1. Відеокарта — найважливіший пункт

| | Що | Навіщо |
|---|---|---|
| ✅ | Hyprland рендерить на Intel, Nvidia друга в списку (`AQ_DRM_DEVICES`) | Менше затримок і проблем Wayland з Nvidia, тихіші вентилятори, довша батарея |
| ✅ | Правило udev створює `/dev/dri/igpu` і `/dev/dri/dgpu` | Імена `card0/card1` змінюються між завантаженнями, симлінки — ні |
| ✅ | Pascal (Quadro P1000–P5200) → `nvidia-580xx-dkms` з AUR | Основний драйвер 590 більше не підтримує Pascal, 580 — остання гілка для нього |
| ✅ | `nvidia-prime` → команда `prime-run` | Запуск окремих програм на Nvidia |

**Перевірка:**

```fish
ls -l /dev/dri/igpu /dev/dri/dgpu     # обидва симлінки існують
echo $AQ_DRM_DEVICES                  # /dev/dri/igpu:/dev/dri/dgpu
nvidia-smi                            # у списку процесів немає Hyprland
prime-run glxinfo | grep "OpenGL renderer"   # має бути Quadro
```

🖐 **CUDA для Varmir:** став `cuda` після драйвера і перевір, що pacman не пропонує замінити `nvidia-580xx-utils` на звичайний `nvidia-utils`. Якщо пропонує — відмовся і візьми CUDA-пакет, сумісний із гілкою 580.

🖐 **Оновлення:** якщо після `paru -Syu` пропав графічний режим, найчастіше DKMS не зібрав модуль під нове ядро. Перевір, що встановлені `*-headers` для кожного ядра: `pacman -Q | grep headers`.

## 2. Оптимізовані пакети (за бажанням)

| | Що | Навіщо |
|---|---|---|
| 🖐 | `./install.sh --cachyos` | Репозиторії CachyOS: пакети Arch, перезібрані під x86-64-v3 з LTO, і ядро `linux-cachyos` |

Перевірити, чи процесор підтримує x86-64-v3 (Coffee Lake у Precision 7530 має підтримувати):

```fish
/lib/ld-linux-x86-64.so.2 --help | grep supported
```

Старе ядро `linux` лишається в меню завантаження як запасне.

## 3. Hyprland (`~/.config/hypr/modules/look.lua`)

| | Налаштування | Навіщо |
|---|---|---|
| ⚙️ | Розмиття `size 6`, `passes 2`, лише для шарів Quickshell | Розмиття під кожним вікном — найдорожчий ефект. Вікна непрозорі, скло лише на панелях |
| ⚙️ | `xray = true`, `new_optimizations = true` | Плаваючі вікна не перемальовують тайлові під собою |
| ⚙️ | Масштаб екрана рівно `1` | Дробовий масштаб (1.25, 1.5) навантажує GPU і погано підтримується частиною застосунків |
| ⚙️ | `render.direct_scanout = 2` | Ігри на весь екран — в обхід композиції, менша затримка |
| ⚙️ | Анімації 150–300 мс, без пружин | Коротка анімація відчувається швидшою за довгу «плавну» |
| ⚙️ | VFR не вимкнено (`debug.vfr`, за замовчуванням увімкнено) | Коли на екрані нічого не змінюється, Hyprland не малює нових кадрів |

**Виміряти кадри:** тимчасово додай у `look.lua` блок `debug = { overlay = true, vfr = false }` і виконай `hyprctl reload`. Після перевірки прибери: з вимкненим VFR батарея сідає швидше.

## 4. Живлення

| | Що | Навіщо |
|---|---|---|
| ✅ | `power-profiles-daemon` | Профілі «Енергозбереження / Збалансований / Продуктивність», перемикаються з оболонки |
| 🖐 | Не став разом із ним TLP | Вони конфліктують |

Якщо все ж перейдеш на TLP: у `/etc/tlp.conf` підніми `INTEL_GPU_MIN_FREQ_ON_AC` і `INTEL_GPU_MIN_FREQ_ON_BAT` (наприклад, з 300 до 500). Інакше на Intel можливі підтормажування.

## 5. Пам'ять

| | Що | Навіщо |
|---|---|---|
| ✅ | zram (zstd, до 8 ГБ) замість swap на диску | Коли пам'ять закінчується, система стискає сторінки в RAM, а не «замерзає» на диску |
| ✅ | `vm.swappiness=180`, `vm.page-cluster=0` та ін. | Налаштування під zram з ArchWiki |

```fish
zramctl            # пристрій zram0, алгоритм zstd
swapon --show      # zram0 з пріоритетом 100
```

## 6. Оболонка без опитувань

Панелі на скриптах (Polybar, EWW) часто щосекунди запускають `pactl`, `nmcli` чи `acpi`. Через це в простої постійно навантажений процесор і з'являються мікрозатримки.

Quickshell отримує все подіями:

- робочі столи і вікна — з сокета Hyprland;
- звук — з PipeWire;
- батарея — з UPower;
- сповіщення — з D-Bus;
- годинник — один раз на хвилину.

Список застосунків для Spotlight тримається в пам'яті. Файли шукаються через `plocate` за готовим індексом (оновлюється щогодини), із затримкою 120 мс після останньої літери, тож диск під час набору не сканується.

```fish
btop    # фільтр «qs»: у простої ~0% CPU
```

🖐 **Правило на майбутнє:** нові віджети пиши на сервісах Quickshell (`Quickshell.Services.*`, `Quickshell.Hyprland`). Не використовуй `Process` з таймером, якщо є подієвий варіант.

## 7. Запуск системи

```fish
systemd-analyze                 # загальний час
systemd-analyze blame | head    # найповільніші служби
```

🖐 Вимкни те, чим не користуєшся: `sudo systemctl disable --now <служба>`. Часті кандидати — `ModemManager` і `cups`, якщо немає модему чи принтера.

## 8. Відео в браузері

✅ `intel-media-driver` + `LIBVA_DRIVER_NAME=iHD`

```fish
vainfo    # список профілів H.264/HEVC/VP9 — апаратне декодування працює
```

🖐 У Firefox перевір `about:support` → «Hardware Video Decoding». У Chromium відкрий `chrome://gpu`.

## 9. Орієнтири «все літає»

| Показник | Ціль |
|---|---|
| Spotlight від натискання до появи | ≤ 150 мс |
| Перемикання робочого стола | 300 мс, рівно, без ривків |
| CPU у простої (усе разом) | ≤ 2% |
| RAM після входу, без браузера | орієнтовно ≤ 1 ГБ |
| Кадри під час анімацій (`debug.overlay`) | стабільні 60 на панелі 60 Гц |
